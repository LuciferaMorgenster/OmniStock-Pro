## 🇬🇧 English

### Overview
OmniStock Pro provides enterprise operators with real-time stock visibility across multiple logistics hubs. Designed to eliminate stock discrepancies, the system orchestrates physical stock tracking, automatic reorders, barcode labels, and seamless synchronization with your business application ecosystem.

### Key Features
1. **Multi-Warehouse Stock Control**:
   - Manage multiple facilities (e.g., Amsterdam Central Hub, Rotterdam Port Terminal, Utrecht Regional Depot, Antwerp Gateway Terminal).
   - Track storage utilization, manager attribution, and inter-facility stock rebalancing.
2. **Unified 2-Way Suite Integrations**:
   - **TalentPulse-HRIS**: Synchronizes staff shifts, warehouse picker assignments, and physical count audit author tracking.
   - **Kopilot Projects**: Automatic Bill-of-Materials (BOM) reservations, material burn rates, and project task requisitions.
   - **BoekhoudGemak**: Real-time general ledger valuation (FIFO / Weighted Average), automated Cost of Goods Sold (COGS) journal entries, and VAT/BTW calculations.
3. **Automated SKU Coding & Pattern Generator**:
   - Automated inventory SKU creation using predefined enterprise standards (`CATEGORY-DATE-RANDOM`, e.g. `HDW-261110-B84K`, `CATEGORY-YEAR-SEQ`, or `OMNI-CATEGORY-CODE`).
   - Ensures uniform coding across logistics warehouses and automatic EAN/UPC barcode generation.
4. **Progressive Web App (PWA) & Offline Vault**:
   - Installable on desktop and mobile directly from [https://omnistock-pro.lucifera.eu](https://omnistock-pro.lucifera.eu).
   - Offline-first cache ensures warehouse pickers and auditors can inspect and recount inventory even during network outages.
5. **Multilingual Architecture & SEO**:
   - Native 4-language support (English, Dutch, German, French) with real-time dynamic SEO tag updates (`title`, `description`, `og:image`, `twitter:image`, `hreflang`, and Schema.org JSON-LD).
6. **Cloud Snapshots & Recovery**:
   - Comprehensive point-in-time disaster recovery snapshots with JSON and CSV export/import capabilities.
